# Microsoft Financial Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Financial Analysis Dashboard developed using Microsoft Power BI. The dashboard analyzes Microsoft's sample financial dataset to provide insights into sales performance, profitability, discounts, customer segments, and regional trends, helping support data-driven business decisions.

## Objectives
- Analyze overall sales and profit performance.
- Compare sales across countries and market segments.
- Identify top-performing products.
- Evaluate the impact of discounts on profitability.
- Monitor key financial KPIs through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Key KPIs
- Total Sales
- Total Profit
- Total Units Sold
- Gross Sales
- Total Discounts
- Cost of Goods Sold (COGS)

## Dashboard Features
- Sales Analysis by Country
- Profit Analysis by Product
- Segment-wise Sales Performance
- Monthly Sales Trends
- Interactive Slicers and Filters
- KPI Cards and Business Insights

## Key Insights
- Identified the countries generating the highest sales and profits.
- Compared product performance across different market segments.
- Evaluated the effect of discounts on overall profitability.
- Analyzed monthly trends to identify seasonal business patterns.
